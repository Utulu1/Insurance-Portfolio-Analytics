# Dataset

This project uses motor insurance portfolio data covering the 2022–2024 reporting period.

The dataset supports analysis of:

- Premium and incurred claims
- Loss ratios
- Claim frequency
- Claim severity
- Portfolio exposure
- Policy type
- Vehicle age
- Business type
- Year-on-year portfolio performance

The raw dataset is not included in this repository. This folder documents the data used to develop the analytical solution.
